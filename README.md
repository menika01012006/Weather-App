# Weather-App

WeatherNow is a weather application built using HTML, CSS, and JavaScript. It uses WeatherAPI to retrieve current weather information for a searched city or the user's current location.

##  Features

- Search weather by city name
- Fetch weather using browser geolocation
- Display current temperature and weather conditions
- Show humidity, wind speed, feels-like temperature, and UV index
- Responsive dashboard design

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- WeatherAPI

##  What I Learned

- Fetching API data using `fetch()`
- Working with asynchronous JavaScript using `async/await`
- DOM manipulation and event listeners
- Using browser geolocation
- Updating the UI with API responses

##  How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Allow location access or search for a city.

##  Security Note

Configure your API key securely before deploying the project publicly. Never commit private API keys to a public repository.
